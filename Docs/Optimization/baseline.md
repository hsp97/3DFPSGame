# 최적화 기준선 (최적화 전)

측정일: 2026-10-30, 씬: `Assets/01.Scenes/GameScene.unity`, Unity 6000.3.22f1 (URP 17.3.0)
원본 데이터: `baseline.json` (시점 7곳 x 미니맵 켬/끔 + 좀비 10마리 테스트)

## 측정 방법

- 에디터 모드에서 `Main Camera`를 고정 위치/회전으로 옮기고, Game 뷰가 여러 프레임 다시 그려진 뒤 `UnityEditor.UnityStats` 값을 읽는다(시점마다 약 16 에디터 틱 대기). 측정이 끝나면 카메라와 미니맵 카메라 상태를 원래대로 되돌린다.
- 같은 방식으로 최적화 후에도 같은 시점에서 측정한다.
- 에디터 측정이라 시간(ms)은 신뢰할 수 없어서 기록하지 않았다(`renderTimeMs`는 0으로 나옴). 배치/SetPass/삼각형 같은 상대 지표로 비교한다.
- 삼각형/정점 수는 그림자 패스(캐스케이드 4개)와 여러 렌더 패스를 포함한 값이라 씬 메시 삼각형 합보다 훨씬 크다.
- 값은 같은 시점에서 약 +-1천 삼각형, +-5 배치 정도 흔들린다.

## 분석: 부하의 대부분은 맵이 아니라 플레이어 모델

씬의 활성 정적 MeshRenderer 삼각형 합은 약 59만이고, 그중 맵 프롭은 대부분 수십~수백 삼각형이다. 반면:

| 메시 | 위치 | 삼각형 | 정점 | 비고 |
| --- | --- | ---: | ---: | --- |
| `texture_mapping` (SkinnedMeshRenderer) | `Player/CallOfDuty_Ghost` | 500,000 | 360,180 | 그림자 캐스터 켬 |
| `texture_mapping` (MeshRenderer) | `…/RightHand/Katana` | 500,000 | 310,418 | 그림자 캐스터 켬 |
| `Barrel_LOD0` | `FireBarrel` x4 | 7,130 | | 이미 LODGroup 있음 |

- 플레이어 모델(Ghost)과 검(Katana)이 각각 50만 삼각형이라, 시점 안에 들어오거나 그림자를 드리울 때마다 메인 패스와 그림자 캐스케이드 4개에서 반복 그려진다. V1(플레이어가 시야에 들어오는 시점)이 6.18M 삼각형인 반면, 플레이어가 없는 V5는 38K 삼각형이다.
- 두 FBX 모두 `Generate Mesh LODs`가 꺼져 있다.
- 따라서 이번 최적화에서 효과가 가장 큰 대상은 맵 프롭이 아니라 **Katana(정적 메시)와 Ghost(스킨드 메시)의 Mesh LOD**다.
- 좀비 프리팹은 SkinnedMeshRenderer 14개, 합계 약 4,900 삼각형으로 가볍다(좀비 10마리 추가 시 약 +17만 삼각형, +492 배치, +12 SetPass는 주로 배치 수 때문).
